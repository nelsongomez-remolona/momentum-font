# antarctica-meteorites

Analysis of Antarctic meteorites from The Meteoritical Society "Meteorite
Landings" catalogue (45,716 records; ~67% are Antarctic finds).

- **[FINDINGS.md](./FINDINGS.md)** — the surprising insights.
- **[analyze_meteorites.py](./analyze_meteorites.py)** — `python3 analyze_meteorites.py` (needs `pandas`).
- **data/meteorites_world.csv** — full catalogue ([figshare mirror](https://rochester.figshare.com/articles/dataset/Meteorite_Landings/26462452) of NASA Open Data). Snapshot ends ~2013.
